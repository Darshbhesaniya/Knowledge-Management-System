# Streamlit UI - Knowledge Management System

This directory contains the Streamlit web application for the Knowledge Management System.

## Running the Streamlit App

From the project root or from this directory:

```bash
# Using uv:
uv run streamlit run src/streamlit_ui/app.py

# Or using pip/python:
python -m streamlit run src/streamlit_ui/app.py
```

For the complete project setup instructions, architecture diagram, and prerequisites, please refer to the main [README.md](../README.md).
